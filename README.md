# AI Spend Audit Platform

An AI-powered spend optimization platform that helps teams detect redundant AI subscriptions, overspending, and optimization opportunities across modern AI tooling stacks.

## Live Demo

https://ai-spent-audit-snowy.vercel.app/

---

## Features

- AI tooling spend analysis
- Subscription optimization recommendations
- Executive AI-generated summaries
- Estimated monthly + annual savings
- Responsive dark-mode dashboard
- Multi-tool stack analysis
- Team-size aware recommendations
- OpenAI-powered insights

---

## Tech Stack

- Next.js 16
- TypeScript
- Tailwind CSS
- OpenAI API
- Vercel Deployment

---

## Installation

```bash
git clone <repo-url>
cd ai-spend-audit
npm install
```

Create `.env.local`

```env
OPENAI_API_KEY=your_key_here
```

Run locally:

```bash
npm run dev
```

---

## Build

```bash
npm run build
```

---

## Deployment

Deployed using Vercel.

```bash
npx vercel --prod
```
